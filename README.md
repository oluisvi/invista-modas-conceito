# Invista Modas — conceito de vitrine digital

Protótipo estático, mobile-first e independente para explorar uma vitrine complementar ao Instagram da Invista Modas.

## Demonstração

[Ver protótipo publicado](https://oluisvi.github.io/invista-modas-conceito/)

## Abrir localmente

Abra `index.html` diretamente ou sirva esta pasta localmente com `python -m http.server 8769`.

## Experiência

- Três estruturas completas: Editorial, Vitrine direta e Lookbook.
- Busca e filtros de referências conceituais sem repetir itens.
- Detalhe acessível para cada referência e links para os canais listados na bio oficial.
- Prancha visual responsiva em `arte/prancha.html`; imagem final em `arte/invista-modas-prancha.png`.

## Limites

Esta página é um conceito de apresentação, não um site oficial nem uma loja funcional. Imagens são geradas e itens são inspirações visuais; não correspondem a catálogo, estoque, preço, marca ou disponibilidade da Invista. O atalho do WhatsApp é o link público da bio e não revela o telefone. Não há checkout, estoque, pagamentos nem CMS.

Leia `BRIEF_DO_PROJETO.md` e `ASSET_CREDITS.md` antes de apresentar.
